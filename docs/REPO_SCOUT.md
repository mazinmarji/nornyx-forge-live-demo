# Repo Scout and Qualifier

Repo Scout derives search terms from the BRD, queries GitHub public metadata, and ranks a bounded candidate set. The Qualifier can inspect a URL or local path.

Scores are separated into business fit, architecture fit, delivery readiness, Nornyx compatibility, agentic runtime fit, security, and legal/maintainability. Hard stops override the aggregate score.

The output is evidence for a foundation decision, not a legal opinion or proof that an unexecuted project builds.
