# Repo Scout

Run `nornyx-forge scout` after extracting stack, capability, architecture, license, maintenance, testing, Docker, and governance requirements from the BRD.

Do not select by popularity alone. Produce a candidate scorecard and distinguish metadata observations from verified build evidence. Never adopt a repository without a usable license observation and exact revision lock.
